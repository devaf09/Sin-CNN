# Sin-CNN — 光の干渉で学習器を作る試み

正弦波（光）の干渉と回折で、ニューラルネットワークの層を置き換えられないか。最終的には、光や音の物理素子でそのまま再現できる学習器にできないか。
このリポジトリは、その構想（[CONCEPT.md](CONCEPT.md)）から始めた実験の記録です。

**現在の到達点**: 固定の光学媒質＋閉形式の読み出しによる言語モデル [03_Opticlm](03_Opticlm/) です。
検証の結果、**言語モデルとしては同じバイト数の n-gram に勝てません**。
一方で「光で作れて、粗いアナログ素子でも壊れず、学習を厳密に足し引きできる」ことは確認できました。

## 結論の要約（2026-10-13。CC-100 日本語 1000万文字）

| | 内容 |
|---|---|
| ✅ 確認できた | 学習が足し算なので、追加学習・取り消し・融合・並列学習が厳密（誤差 1e-16）。勾配で学習する方式（01・02）にはできない |
| ✅ 確認できた | 光学の特徴は、同じ次元のデジタルのランダム特徴と同等か、わずかに良い。回折（位相板＋伝播）は必須 |
| ✅ 確認できた | 読み出しの重みは 4〜5bit、素子のばらつき 10%、検出器 光子100/画素・ADC 6bit で動く（nll の悪化は合計約 0.04） |
| ❌ 否定された | 軽さ：同じバイト数では Kneser-Ney n-gram が全面的に上（acc1 40.4 vs 35.0）。データを増やしても差は広がる |
| ❌ 否定された | n-gram の混合補助：強い n-gram 相手では、同じバイト数の n-gram を足すのと差がない |
| ❌ 否定された | 特徴の増強（参照光・長距離）、2段カスケード、確信度による切り替え：効果なし |
| ⚠️ 未検証 | 構想にある「スケール不変」「ブラックボックスの回避」「時間・電力ほぼゼロ」。実機での動作 |

数字と手順は [03_Opticlm/RESULTS.md](03_Opticlm/RESULTS.md) にあります。構想とコードの問題点の自己批判は [03_Opticlm/REVIEW.md](03_Opticlm/REVIEW.md) にあります。

## 構想（CONCEPT.md）の主張と、検証の状況

| 構想の主張 | 状況 |
|---|---|
| 空間周波数の少数パラメータで層を表す（O(N²) → O(N)） | 01〜02 の実装では、位相マップが「x だけの関数 + y だけの関数」に限られ、256 周波数のうち実効的な自由度は約 50 だった。モデルの重さの 98% はデジタルの埋め込みと出力層だった（REVIEW.md A2・A3） |
| 学習パターンの融合（位相の乗算）で再学習を不要にする | 位相の乗算による融合は検証していない。代わりに 03 では「統計量の足し算」による厳密な融合・取り消しを実現した |
| seed から層を再現でき、重みを保存しなくてよい | 03 で実現した（光学媒質は seed から再現）。ただし保存が必要な読み出し W が大部分を占める |
| 計算は光速で、時間・電力ほぼゼロ | 未検証。SLM の書き換え速度、カメラの読み出し、ADC、デジタルの読み出し（W）のコストは含まれていない |
| カオス的な鋭敏性で共通点が鋭くなる | 03 では逆に、検出器の雑音や素子のばらつきに強い（鋭敏でない）ことが利点になった |
| スケール不変、ブラックボックスの回避 | 未検証 |

### 既知の問題（01・02 のコード）

- **伝播の誤り**: PoC 03〜06 と 02 の全ファイル（学習・推論）では、角スペクトル伝播の伝達関数 H を中心が真ん中の並び（`linspace(-N/2, N/2-1)`）で作っています。それを `fftshift` していない `fft2` の出力に掛けているので、実際の光の伝播と一致しません（同じ入力で強度の相対差 0.99）。学習は「固定の位相の掛け算」として動いてしまいますが、出力した位相マスクを実機に作っても同じ動作はしません。修正は `fx = torch.fft.fftfreq(N, d=DX)` に置き換えることです。PoC 01・02 と 07 以降（03_Opticlm を含む）は正しい並びです。履歴として残すため、01・02 のコードは修正していません。
- **評価**: 04・05・02 は学習データでの正解率だけを表示しています。言語モデルとしての能力（未知の文での予測）は測れていません。

## 使い方

03_Opticlm の [README](03_Opticlm/README.md) を見てください。必要なのは `numpy` だけです（`torch` があれば GPU も使えます）。

```
cd 03_Opticlm
python opticlm.py selftest
python example.py
```

01・02 のスクリプトは `torch`・`numpy`・`matplotlib`（PoC 03 は `scikit-learn` も）で動きます。
